# Khmer–English glossary of school and technical terms · វាក្យសព្ទបច្ចេកទេស ខ្មែរ–អង់គ្លេស

Sulvana's Khmer tools use this list so that school and technical words are understood correctly
(for example ជាលិកា is "tissue", not "category"). One term per line: Khmer = English.

- វិសាខបូជា = Visak Bochea
