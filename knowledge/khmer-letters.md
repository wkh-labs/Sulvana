# Formal Khmer letter layout · ទម្រង់លិខិតផ្លូវការជាភាសាខ្មែរ

A formal Khmer letter (to a school, office, ministry or employer) follows a fixed layout:

1. At the top, centred, the national heading on two lines:
   ព្រះរាជាណាចក្រកម្ពុជា
   ជាតិ សាសនា ព្រះមហាក្សត្រ
2. The recipient, starting with «សូមគោរពជូន» (to someone senior) — for example «សូមគោរពជូន លោកនាយកសាលា» or «សូមគោរពជូន លោកគ្រូ/អ្នកគ្រូប្រចាំថ្នាក់»។
3. «កម្មវត្ថុ៖» (subject), one line saying what the letter asks for.
4. Optionally «យោង៖» (reference) to an announcement or earlier document.
5. The body, which usually opens with «តបតាមកម្មវត្ថុខាងលើ» (regarding the subject above), introduces the writer
   («ខ្ញុំបាទ» for a man, «នាងខ្ញុំ» for a woman, then the name and position or class), and states the request politely.
6. A closing request: «អាស្រ័យដូចបានជម្រាបជូនខាងលើ សូម … មេត្តាពិនិត្យ និងអនុញ្ញាតដោយក្ដីអនុគ្រោះ។»
7. The courtesy line: «សូម … មេត្តាទទួលនូវការគោរពដ៏ខ្ពង់ខ្ពស់អំពីខ្ញុំ។»
8. Bottom right: the place and date, for example «រាជធានីភ្នំពេញ ថ្ងៃទី … ខែ … ឆ្នាំ …», then the writer's signature and full name.

# Letter asking a teacher for leave · លិខិតសុំច្បាប់ឈប់សម្រាកពីគ្រូ

ព្រះរាជាណាចក្រកម្ពុជា
ជាតិ សាសនា ព្រះមហាក្សត្រ

សូមគោរពជូន លោកគ្រូ/អ្នកគ្រូប្រចាំថ្នាក់ទី …

កម្មវត្ថុ៖ សំណើសុំច្បាប់ឈប់សម្រាករយៈពេល ១ ថ្ងៃ ដោយសារមានជំងឺ។

តបតាមកម្មវត្ថុខាងលើ ខ្ញុំបាទ/នាងខ្ញុំឈ្មោះ … ជាសិស្សរៀនថ្នាក់ទី … សូមគោរពជម្រាបជូន លោកគ្រូ/អ្នកគ្រូ មេត្តាជ្រាបថា ខ្ញុំមានជំងឺ … មិនអាចមកសិក្សាបាននៅថ្ងៃទី … ខែ … ឆ្នាំ … បានទេ។

អាស្រ័យដូចបានគោរពជម្រាបជូនខាងលើ សូមលោកគ្រូ/អ្នកគ្រូ មេត្តាអនុញ្ញាតច្បាប់ដល់ខ្ញុំ ដោយក្ដីអនុគ្រោះ។

សូមលោកគ្រូ/អ្នកគ្រូ មេត្តាទទួលនូវការគោរពដ៏ខ្ពង់ខ្ពស់អំពីខ្ញុំ។

… ថ្ងៃទី … ខែ … ឆ្នាំ …
ហត្ថលេខា និងឈ្មោះសិស្ស

A note from a parent can be added under the student's signature: «បានឃើញ និងឯកភាព» with the parent's signature and name.

# Job application letter · ពាក្យសុំការងារ

ព្រះរាជាណាចក្រកម្ពុជា
ជាតិ សាសនា ព្រះមហាក្សត្រ

សូមគោរពជូន លោក/លោកស្រី នាយកក្រុមហ៊ុន …

កម្មវត្ថុ៖ ពាក្យសុំបម្រើការងារជា …
យោង៖ សេចក្ដីជូនដំណឹងជ្រើសរើសបុគ្គលិក ចុះថ្ងៃទី … (if there was an announcement)

តបតាមកម្មវត្ថុ និងយោងខាងលើ ខ្ញុំបាទ/នាងខ្ញុំឈ្មោះ … កើតថ្ងៃទី … ខែ … ឆ្នាំ … បច្ចុប្បន្នរស់នៅ … សូមដាក់ពាក្យសុំបម្រើការងារជា … នៅក្នុងក្រុមហ៊ុនរបស់ លោក/លោកស្រី។ (Then two or three sentences on education, skills and experience.)

អាស្រ័យដូចបានជម្រាបជូនខាងលើ សូម លោក/លោកស្រី មេត្តាពិនិត្យ និងផ្ដល់ឱកាសឱ្យខ្ញុំបានចូលសម្ភាសន៍ ដោយក្ដីអនុគ្រោះ។

សូម លោក/លោកស្រី មេត្តាទទួលនូវការគោរពដ៏ខ្ពង់ខ្ពស់អំពីខ្ញុំ។

… ថ្ងៃទី … ខែ … ឆ្នាំ …
ហត្ថលេខា និងឈ្មោះ

Attach: CV (ប្រវត្តិរូបសង្ខេប), copies of the ID card and diplomas, and photos if asked.

# Informal messages · សារមិនផ្លូវការ

Messages to friends or family do not use the national heading or «កម្មវត្ថុ». Start with a greeting («ជម្រាបសួរ» to an
older person, «សួស្ដី» to a friend), say what you want simply, and end with «អរគុណ» or «សូមអរគុណច្រើន»។
