# Khmer Conversational Style and Natural Phrasing · របៀបសរសេរ និងការសន្ទនាជាភាសាខ្មែរ

## Greetings and Politeness · ការស្វាគមន៍ និងសុជីវធម៌ក្នុងការសន្ទនា
- សួស្តី (Hello / Greetings)៖ ប្រើសម្រាប់ស្វាគមន៍ទូទៅដោយភាពរាក់ទាក់។ ឧទាហរណ៍៖ «សួស្តីបាទ! តើថ្ងៃនេះអ្នកសុខសប្បាយជាទេ?» ឬ «សួស្តី! មានអ្វីឱ្យខ្ញុំជួយដែរទេ?»
- អរគុណ (Thank you)៖ ប្រើ «សូមអរគុណ» ឬ «អរគុណច្រើន» សម្រាប់បង្ហាញការដឹងគុណ។
- ការឆ្លើយតបគួរសម៖ «មិនអីទេបាទ» (You're welcome / No problem), «ដោយសេចក្តីរីករាយ» (With pleasure)។
- ពាក្យគួរសមជំនួយការ៖ ប្រើ «បាទ» (សម្រាប់បុរស ឬជំនួយការបែបផ្លូវការ) ដោយសមរម្យ មិនប្រើញឹកញាប់ពេកក្នុងមួយប្រយោគ។

## Natural Sentence Connectors · ឃ្លាភ្ជាប់សេចក្តីបែបធម្មជាតិ
- ជាបឋម / ដំបូងបង្អស់ (Firstly / To begin with)
- លើសពីនេះទៅទៀត / ម្យ៉ាងវិញទៀត (Furthermore / In addition)
- ផ្ទុយទៅវិញ / ទោះជាយ៉ាងណាក៏ដោយ (On the contrary / However)
- ជាពិសេស (Especially / Particularly)
- ឧទាហរណ៍ដូចជា (For example / Such as)
- សរុបមក / ជារួម (In summary / Overall)

## Punctuation and Formatting · ក្បួនវណ្ណយុត្តិ និងទម្រង់អត្ថបទ
- សញ្ញាខណ្ឌ (។)៖ ត្រូវប្រើនៅចុងបញ្ចប់នៃប្រយោគនីមួយៗជានិច្ច។
- គម្លាត (Spaces)៖ ភាសាខ្មែរមិនដកឃ្លារវាងពាក្យទេ ប៉ុន្តែដកឃ្លារវាងកន្សោមពាក្យ (Clauses) ឃ្លា ឬក្រោយសញ្ញាវណ្ណយុត្តិ។
- បញ្ជីចំណុច (Bullet points / Numbering)៖ ពេលពន្យល់ជំហាន ឬចំណុចច្រើន ត្រូវប្រើលេខរៀងខ្មែរ (១, ២, ៣) ឬសញ្ញាដក (-) ដើម្បីឱ្យអានស្រួល និងមានរបៀបរៀបរយ។

## Technical and Modern Terms · ពាក្យបច្ចេកវិទ្យា និងពាក្យទូទៅ
- Artificial Intelligence (AI)៖ បញ្ញាសិប្បនិម្មិត (AI)
- Computer / Laptop៖ កុំព្យូទ័រ / កុំព្យូទ័រយួរដៃ
- Internet / Web / Online៖ អ៊ីនធឺណិត / គេហទំព័រ / អនឡាញ
- Software / Hardware៖ កម្មវិធី (Software) / ផ្នែករឹង (Hardware)
- Smartphone / Phone៖ ស្មាតហ្វូន / ទូរសព្ទឆ្លាតវៃ / ទូរសព្ទ
- Programming / Code៖ ការសរសេរកូដ (Coding/Programming)
